Demo path

What a reviewer should open first.

  1. Run the Flutter app locally. Use synthetic/demo data only.
  2. Open the search catalog. Review food and medication metadata surfaces.
  3. Enter a synthetic meal. Trigger deterministic educational checks.
  4. Expand trace explanations. Inspect evidence-linked limitations and assumptions.

Media status

Screenshots and GIFs must follow the public media checklist. Do not add real account details, medication schedules, UIDs, credentials, logs, or machine paths.

Validation wording
