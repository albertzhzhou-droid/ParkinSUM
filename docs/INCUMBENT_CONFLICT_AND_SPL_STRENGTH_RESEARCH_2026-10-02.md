# 既有事实冲突、导入激活与药品强度依据

本轮接续用户要求的完整冲突引擎及更丰富饮食/药品数据，沿用活动库原地实施。当前为本地未提交候选，算法 schema 6、版本 `2026.10.02-v65`，没有发布或更新实际用户目录。原 NEXT 与 MEGA 规划、V5 的验收身份和全部历史记录保留；新增范围的完整目标仍在进行。

## 实际反例与结果

修改前执行四个功能反例，实际 51 项通过、4 项失败：同一输入 10 与已有事实 10 和 1 比较时，首个重叠值隐藏矛盾；完整簇忽略传入的已有事实；未解决导入仍创建激活标记；扩展营养证据被误标为使用了不存在的旧数值字段。失败原日志保留为 `/private/tmp/parkinsum-027-preimplementation-counterexamples.log`。

修复后的单条比较检查全部已有事实，并保留每个事实的理由，结果不再受输入顺序影响。完整簇恢复已有事实所指的原 observation，再比较来源、方法、范围、单位和计量基准；缺失或不一致的历史证据明确进入 `historical_evidence_required`，不猜测旧方法或分母。旧 observation ID 的内容冲突不能被覆盖。已有人工作出的选择保留，自动导入不能替换它。

批量导入在写入正式目录、标签段落、事实、规则和激活标记之前执行审核；存在矛盾时保留物理暂存与来源证据，产生审核日志和 `held_for_conflict_review`，保持旧快照。单条入口复用同一审核路径。来源文档同 ID 异校验值、同 scope hash 异维度、候选事实与原 observation 不符、全局重复 observation ID 均不能激活。身份含混时先保留审核限制，不在猜测的来源身份下进行排名。

实际本地导入流程遇到审核限制时只执行一次，不立即重试或同步应用目录；保留已解析包与恢复入口。再次明确恢复仍需满足审核条件。旧兼容入口只返回成功导入的包。当前实现保留原审核体系，尚未完成审核决定、历史退役及恢复激活的全部闭环。

## 药品研究与来源字段

核对 [FDA SPL 实施与验证规范](https://www.fda.gov/media/84201/download) 第 3.2.3–3.2.6 节及 [FDA 强度表示说明](https://www.fda.gov/drugs/electronic-drug-registration-and-listing-system-edrls/strength-conversion-drug-listing)：ACTIB、ACTIM、ACTIR 分别按活性成分、活性基团、参考成分表示强度；分子和分母独立保留。这是来源字段解释，不是给药量换算或药物等效判定。

两份保留的官方完整 XML（Sinemet、Rytary）沿用原获取回单，没有重新标成今日抓取。实施前的独立字段冻结包括 8 产品、128 成分：16 活性、112 非活性。新裁剪 XML 仅保留产品与原成分字段，不包括整份标签叙述；检查入库的独立预期不依赖忽略目录中的下载。

旧导入器在正确完整成分裁剪件上实际 8 项失败，缺少成分编码等字段。两个早期测试设置问题的日志也保留，不能作为此项反例的有效证据。修复后按产品保留成分编码和代码体系、活性基团、参考成分、原始强度分子/分母、全部非活性成分身份。只读取相应命名空间的直接结构；缺失或多重强度依据不修补为唯一依据。多重数量保留数组，单值为空。

实际当前导入器再次读取两个完整原响应，由独立脚本逐条比较全部 128 条来源字段、8 产品归属和强度依据，完全一致。实际 source inspection 与软件核对不证明标签事实的临床正确性、完整语义解析或当前全球目录覆盖。原 XML 校验值和获取信息见已有冻结文件。
