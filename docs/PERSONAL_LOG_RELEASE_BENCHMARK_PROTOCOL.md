# 发布版个人记录性能测量协议

此协议定义 W13 的两个独立实验；协议和入口存在不代表实验已执行或通过。实际结果、源码和构建身份记录在本地交付回单中。必须先完成同一公开输入 SHA 的正式入口 W31 九项走查，构建工具才允许生成性能入口。

性能入口在挂载界面之前，与正式入口一样加载并核验离线 IANA 2026e 资产。独立启动观察实际发现旧入口未激活该资产；已补齐启动步骤，并以实际入口测试检查规则身份、覆盖范围及非发布模式阻止测量。该观察不替代下述发布版测量，旧数据不能换用新源码身份。

固定数据使用 seed `31415926`，规模为 100/1,000/10,000 餐食，另有 20/200/2,000 条服药记录。数据包含真实报告零、捕获缺失、非法份量、未来时间及跨类型同名 ID；不得为了使恢复通过而修正这些字段。每个成功阶段执行两次预热、七次测量，以 Stopwatch 微秒换算毫秒，保留原始样本、median 与 nearest-rank p95。失败阶段保留已完成的预热/测量样本、失败迭代和原因，不产生成功 percentile，也不填补零耗时。

## 内存时间线实验

使用独立 ephemeral 服务与实际 TimelinePage。测量固定数据生成、排序、Insights、名称/来源筛选、typed focus、全量近邻索引、ephemeral 初始化、首次两帧和首个显示页的五步滚动。滚动包括至多两次 overshoot 校正，每步须实际挂载原记录。

全页导航是单独阶段：从第一页通过真实公开按钮依次移动到最后一页，每次等待两个完整帧，核对生产页码、精确计数、挂载记录的 typed ID 及最后按钮禁用。200 事件一页，三个规模分别为 1/6/60 页。它不代表滚动条遍历全历史，也不代表所有行完成入场动画。挂载计数只计 `meal:`/`medication:` 原记录，不计分页标签或窗口容器。

## 真实持久化实验

单独按钮、专用 origin、一个可见标签。启动前检查 SharedPreferences；存在任何未标记内容即拒绝，检查早于服务初始化。重用环境必须有完全匹配的源码 marker、local owner、默认档案、空记录及空 Care/草稿。marker/owner 检查不是跨标签锁，也不证明其他标签不能写入。

先写固定数据并精确读回，写入不计入启动耗时。启动阶段使用新建的实际 Services.createDefault、WebAppDatabase 和 AppState；测量服务图加载已落盘数据，不称为浏览器/OS 冷启动或网络冷缓存。目录搜索使用实际随应用提供的目录和六个固定查询；个人记录规模不是目录条目规模。报告阶段尝试完整输入的 countsOnly summary/HTML，并保留 5,000 记录等生产预算阻断；实际 raster PDF 仅使用前 20 餐/4 次服药，不称为完整 10k PDF。

恢复阶段调用现有包生成、prepare、显式确认 commit、精确读回和持久 rollback。只有固定操作 nonce 对应的 generatedAt 改变，事件时间、营养、份量、ID 和目录内容不变。缺失或非法字段造成生产拒绝时，保留拒绝和部分样本。复核 marker、owner、档案及非餐食/服药状态后，仅清理匹配固定数据的行，读回原空状态；发现外来状态则拒绝清理。部分写入和配额失败不转换成成功记录。

## 独立复核

记录实际设备/OS、浏览器版本、viewport、release 构建 ID 和 main.dart.js SHA，以及同源 W31 回单。按真实控制台报告逐组独立复算 median/p95，检查七个有限非负成功样本及规模/fixture SHA。完整输入的失败、预算和配额边界单列；它们不满足成功分布要求。修改源码、工具链、数据或协议后重建并重走相应旅程，不给旧回单替换身份。

已往未分页 release 尝试在完整采样前渲染器崩溃，不能据此生成速度提升百分比。最多两个已实测热点可优化。没有实际测量的 native、耗电、OS 进程恢复、中文 PDF 或临床表现不纳入结论。
