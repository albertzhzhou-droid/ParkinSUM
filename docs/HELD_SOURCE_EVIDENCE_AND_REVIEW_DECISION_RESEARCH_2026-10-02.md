# 待审核来源恢复与明确审核决定

本轮 MEGA-20261002-028 延续原有导入、工单与冲突审计。修改前两项实际反例失败：待审核记录没有完整来源包；附件写入失败会返回普通错误，且没有保存待审核来源。原始失败保留于 `/private/tmp/parkinsum-028-preimplementation-held-evidence.log`。

`ClinicalDecisionSupportService` 在现有 `ingestion_run.notes_json` 保存来源文档全部16个字段、原始观察记录、待审核表行、完整比较图及原冲突审计，并绑定相关历史事实、观察、来源和范围。保存发生在可选附件写入之前。新的 `loadHeldImportReviewEvidence` 可以从新服务实例读取，逐一核对来源包摘要、未激活快照、实际暂存行、原审计和当前历史证据。任一变化都使原审核包失效。附件仍按原平台报告持久性；Web 的 inline 附件仍为会话内存，后台记录保存不冒称该附件已经落盘。

`KnowledgeBaseReleaseService.recordImportConflictReviewDecision` 复用已有工单和审计表，支持选择原观察、要求更正证据和延后审核。决定必须关联实际开放的匹配工单、原始冲突和调用者刚查看的完整证据摘要。选择数量还必须属于该比较图，保留完整原始来源、方法、定位和限定数量。身份碰撞、缺失历史、无法比较的上下文、空方法或无原来源内容不能通过选择一个数值得到修复。决定以新增审计记录保存，保留原工单及原冲突；关闭或忽略工单不会消除 `needs_human_review`。

`isImportConflictReviewDecisionCurrent` 核对决定记录摘要及其关联的当前工单、来源包和原冲突。该判断表示软件证据仍匹配；决定明确记录 `activation_authorized=false`、`clinical_approval=false`。它不会触发正式目录激活、发布或临床批准。

73项导入、来源恢复、明确审核和现有发布阻断测试通过，另39项候选身份与实际证据观察测试通过。独立 Python 核对实际后台写入后从新服务图恢复的所有来源字段、比较图、暂存行、原审计和决定摘要；16个逐字段变异均改变绑定摘要。实际观察仍有1条原冲突，活跃快照、正式来源和正式观察均未增加。此前使用追加行的测试替身改为与原生/Web 相同的主键更新语义；最初21通过/1失败的替身回归原日志保留，没有放宽生产核对。
