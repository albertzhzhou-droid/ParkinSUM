# 全簇冲突比较与营养数量扩展

本轮落实用户追加的完整冲突引擎及更丰富饮食/药品数据目标。MEGA 工作包的旧验收属于原冻结候选；本轮是新增实施，不将旧回单换身份后当作新执行。当前代码仍为活动库本地未提交候选，算法 schema 6、版本 `2026.10.02-v64`。本轮没有更新实际用户目录或发布应用。

## 实际发现与修复

修改前冻结三个反例并执行，三个都失败。宽区间 A=[1,10] 与 B=[1,2]、C=[8,9] 都重叠，但 B、C 彼此不重叠；原引擎只比较排序优选者，遗漏 B–C。原实现也将同一来源文档的不同矛盾行当作重复，并直接比较不同测量方法。

`FactConflictEngine.resolveCluster` 现在输出稳定的完整无向比较图。相同可比上下文中的任何不重叠对都会进入 `review_required`；排序优选记录仍可供复核，但不宣称其值已被证据验证。只有完整相同来源、定位、方法、单位、基准、限定值及原文字段才标记已证明重复；不同方法、不同变体范围分别共存。导入审计保存全部边和人工复核动作。四条记录的六条比较边经过输入排列变化验证，严格小于与小于等于原边界测试保留。

新增方法隔离并不证明“方法代码相同就科学可比”。两个空方法仍沿用旧比较政策，审计明确其方法身份未验证。`existingFacts` 与跨导入历史证据比较、复核工单到批准/撤回的完整事务闭环仍需实现；本轮不以聚类补丁冒称完整引擎目标已经完成。

## 来源研究与新增字段

依据 [USDA Foundation 文档](https://fdc.nal.usda.gov/Foundation_Foods_Documentation/)、[Branded 文档](https://fdc.nal.usda.gov/GBFPD_Documentation/)及[官方下载页](https://fdc.nal.usda.gov/download-datasets/)核对数量身份、单位和来源范围。Foundation 提供采样及分析上下文，缺少某营养项不等于零；不同维生素形式、糖与纤维方法须分别保留。部分农业数据按干物质表达，Branded 中也存在按体积表达的情况，不能默认换算成可食部克数。

复用此前真实取得的 [2026-04 完整 Foundation 归档](https://fdc.nal.usda.gov/fdc-datasets/FoodData_Central_foundation_food_json_2026-04-30.zip)，没有重新获取或改写原归档。压缩文件 SHA-256 为 `186e988ec542e913f51ef62b86a47758e8cdd0d1dc3889e7b055581f3c09c77a`；原 JSON 成员为 `27d1fe3fd89edfbe528ed915da5619320e1d004d4594603a1b19bdb1511590cc`。395 个槽位中实际完整食品 363 个，32 个空槽不生成食物。

结构化数量从13类扩到62类，新49类覆盖：

| 维度 | 新增的独立数量 |
| --- | --- |
| 矿物质 | 钙、镁、磷、锌、铜、锰、硒、碘 |
| 维生素与相关成分 | C、B1/B2/B3/B5/B6/B12、总叶酸、A RAE、视黄醇、α生育酚、D2/D3/总D微克和独立IU、三种K形式、胆碱 |
| 脂质 | 胆固醇、饱和/单不饱和/多不饱和/反式脂肪酸、ALA、EPA、DHA |
| 碳水化合物 | 淀粉、六种单/双糖、两个来源身份独立的总糖数量、可溶/不可溶纤维 |
| 其他 | 来源报告的kJ能量、灰分、氮 |

ID和number只要同时提供就须一致，未知或冲突标识不会被熟悉的显示名称修补。原先正例CSV用虚构的Protein ID=1，已修正为官方1003；原数值、范围和氨基酸断言保持，新增未知ID/冲突ID负例。仅传统且唯一的无标识名称保留兼容入口；Atwater及新增数量仍要求来源ID或number。`µg`/`μg`只规范拼写为`ug`，保留原单位；不换算IU、生物活性当量、密度或源值。

## 实际证据与当前资格

实施前独立冻结49个原始数量身份与源码字段预期。完整原归档实际导入后，用独立Python读取原压缩成员，比较所有新增6,340条摘要记录的食品ID、数量、单位、限定类型、数值、上下界及方法，完整多重集合一致。这批新增摘要均为来源报告exact；检出限行为另由既有及裁剪字段测试验证，不将这批数据冒称检出限覆盖。

另独立比较新增数量的5,671条来源样本范围，食品/数量身份、规范单位、区间限定类型、上下界及方法完整多重集合一致。样本范围不会替代均值或当作点值。

49条裁剪来源字段已作为可随CI执行的fixture保存；不依赖ignored归档。定向回归186项通过；导入审计及49维数据库写入/投影链88项通过，两批有重叠，不相加为独立总数。数据库写入测试使用记录型适配器，证明服务传递与投影契约，不替代SQLite、浏览器持久化或实机存储。原失败日志均保留于本地临时输出。本轮整库检查结果由唯一时间线及当前验收回单记录，旧2,838项/V5构建继续标为历史。

本轮62类数量不等于FDC全部营养或全部食物类型。既有`per_100g_edible_part`导入基准尚需对干物质、体积和来源版本分别建立资格；源事实不生成新的临床规则。22个数值实现与现行参数保留，十二条旧治理记录逐字对象与摘要保留，新候选追加第十三条，资格和批准保持待证据。

本地证据目录为 `build/mega_upgrade/complete_engine_research/`：`preimplementation_expected_source_fields_026.json`、`actual_bulk_quantity_observation_026.json`、`independent_bulk_quantity_review_026.json`、`independent_binding_review_026.json`。这些是ignored本地研究产物，不能被文档链接视为公开发布。

## 继续完成完整目标

下一轮按依赖推进：先补跨导入/已有事实、来源版本及缺失方法的可比性；再把复核结果、撤回与事实激活做成可回放事务，验证矛盾不会进入运行时；随后补食物干物质/体积基准和药品成分、强度分母、活性成分身份及标签版本的独立来源案例，再把相关解释接入详情。现有药品来源、产品范围和活性成分类别保护继续保留。本轮没有新增药品事实，不能以食物字段扩展替代药品数据目标。

药品研究已读取两份保留的完整官方SPL，独立冻结8个产品、128条成分的原名称、成分代码、活性部分代码及强度分子/分母。现有结构化强度尚缺完整活性部分身份，非活性成分审计也未保留全部物质代码。这是实施前来源预期，未改药品导入逻辑。参考[FDA强度表达说明](https://www.fda.gov/drugs/electronic-drug-registration-and-listing-system-edrls/strength-conversion-drug-listing)、[SPL资源](https://www.fda.gov/industry/fda-data-standards-advisory-board/structured-product-labeling-resources)及[DailyMed标签接口](https://dailymed.nlm.nih.gov/dailymed/webservices-help/v2/spls_setid_api.cfm)；标签强度比值不自动成为服用剂量。
