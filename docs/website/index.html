05 / THE LEDGER

Data you can trace.
Changes you can audit.

Food values are copied from official sources and tested back against them. Every change to the model’s configuration appends a ledger record that stays blocked until evidence exists.

With explicit consent, a loopback model may polish existing copy or rerank eligible, rule-screened candidates. It cannot alter hard-rule outcomes, scores, medication data, evidence or safety gates.

A few things worth asking.

Is this showcase the running Flutter app?+

This is an interactive project exhibit. The chapter tour uses real September 2026 app screenshots; the evidence flow and model diagram explain the design. To run the actual app, follow the wiki’s local demo path.

Are the model curves live results?+

The curves on this site are conceptual illustrations without a numerical axis. The project’s own model produces educational sensitivity traces with explicit applicability and uncertainty limits. Neither represents a patient prediction.

What does local-first mean here?+

The public demo path stores its state locally and does not require a production backend. Owner-entered records and exports may still contain sensitive information; local storage is not a claim of encryption or anonymity.

How can I review a capability claim?+

Start with the capability matrix, then open the linked implementation, test or report. Implementation, synthetic fixture agreement, visible rendering and clinical validation are different evidence levels.

Does this site run any scripts?+

No. Chapters, the evidence chain and both archive shelves are chosen with plain form controls and styled with CSS. The site loads no scripts, analytics or remote fonts, and its content security policy allows none.
